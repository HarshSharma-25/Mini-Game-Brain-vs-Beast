# Mini-Game: Brain vs Beast

A simple mini-game created with HTML, CSS, and JavaScript.

🎮 **[Play the Live Game Here!](https://mini-game-brain-vs-beast.onrender.com)**

## Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.
3. Enjoy the game!

## Project Structure

- `index.html`: The main HTML file containing the structure of the game.
- `style.css`: The stylesheet for the game.
- `src/game.js`: The game logic.
- `server.js`: A simple Node.js server (if applicable).
- `assets/`: Contains the images and sounds used in the game.
